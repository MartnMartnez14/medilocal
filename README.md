# MediLocal

Aplicación local desarrollada en Python y SQLite para gestionar medicamentos y suplementos asociados a perfiles de personas y mascotas.

## Funcionalidades

- Crear perfiles de personas y mascotas.
- Registrar medicamentos.
- Registrar suplementos.
- Consultar los registros asociados a cada perfil.
- Editar medicamentos y suplementos.
- Eliminar registros.
- Almacenar los datos en una base de datos SQLite local.

## Tecnologías

- Python 3
- SQLite
- Git
- GitHub
